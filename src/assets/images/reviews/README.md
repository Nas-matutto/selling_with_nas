# Review screenshots

Drop your customer review screenshots in THIS folder (png / jpg / jpeg / webp / avif).

- They are picked up automatically by the Live Session page marquee — no code changes needed.
- Files are shown in filename order, so name them `review-01.png`, `review-02.png`, ... to control the sequence.
- Portrait-ish screenshots (like a tweet or a chat message) look best; cards are 300px wide and keep each image's aspect ratio.
- Delete a file to remove that review.
